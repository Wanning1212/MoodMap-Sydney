MoodMap Sydney

Not sure where to go? Start with how you feel.

Ever wanted to go somewhere in Sydney, but had absolutely no idea where?

Maybe you've had a stressful week. Maybe you're feeling adventurous. Or maybe you just want to get out of the house.

MoodMap Sydney is a little interactive map that helps you discover places around Sydney based on your mood.

No endless scrolling. No complicated planning. Just pick a feeling and see where it takes you!

How to Play

1. Pick a mood — How are you feeling right now?

2. Explore the map — Look for the highlighted locations.

3. Follow your curiosity — Click a marker to see photos and details.

4. Try another mood — There's always somewhere new to discover!

Made With

Processing 4 + Python Mode

Language: Processing Python

External libraries: None

The project uses built-in Processing functions for drawing, mouse interactions and displaying images. No GPS, external APIs or live data are needed.

Run It Yourself！

Click Code → Download ZIP.
Unzip the downloaded file.
Open the `MoodMap_Sydney` folder inside the downloaded project.
Open `MoodMap_Sydney.pyde` in Processing 4 with Python Mode selected.
Click ▶ Run and start exploring!

Make sure the `data` folder stays inside `MoodMap_Sydney` so all location photos load correctly.
